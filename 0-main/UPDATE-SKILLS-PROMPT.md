# 🔄 Промпт: «Обнови мои скиллы из библиотеки»

Для тех, кто **уже** пользуется библиотекой. Смотрит удалённый репозиторий, сравнивает
с тем, что у тебя уже установлено, и докидывает **только новое и полезное** — то, чего
у тебя ещё нет. Ничего лишнего не переустанавливает и не ломает.

Парный к [TEAM-ONBOARD-PROMPT.md](TEAM-ONBOARD-PROMPT.md): онбординг — для первого раза,
этот — для регулярного обновления.

**Как использовать:**
1. Открой своего агента (**Claude Code или Codex**) в любой папке.
2. Скопируй весь блок ниже.
3. Заполни блок «О СЕБЕ» (или напиши «как в прошлый раз») и отправь.

---

```
Ты — апдейтер моей библиотеки скиллов. Я УЖЕ ей пользуюсь. Твоя задача: посмотреть
свежую версию репозитория, сравнить с тем, что у меня уже стоит, и предложить
доустановить только НОВОЕ и полезное — то, чего у меня ещё нет. Не переустанавливай
то, что уже работает, и ничего не удаляй.

## Шаг 1. Забери свежую версию библиотеки
Библиотека: https://github.com/MichaelTarasov02/Skills

- если у меня уже есть клон (обычно `~/team-skills`) — обнови его:
    cd ~/team-skills && git pull
- если клона нет — склонируй:
    git clone https://github.com/MichaelTarasov02/Skills.git ~/team-skills

Источник истины внутри: папки `*/SKILL.md` (скиллы) и `agents/*/` (агенты-плагины),
плюс `0-main/SKILLS_CHEATSHEET.md` (кураторские подсказки, может отставать — сверяй
с папками).

## Шаг 2. Посмотри, что у меня УЖЕ есть
Собери актуальный список установленного, не полагаясь на память:
- скиллы: перечисли имена папок в `~/.agents/skills/`, `~/.claude/skills/`,
  `~/.codex/skills/` (что применимо к моему хосту);
- агенты-плагины: `claude plugin list` (в Claude Code).
Это «уже есть».

## Шаг 3. Посчитай дельту (что нового в репо)
- **Новые скиллы**: папки `*/SKILL.md` в клоне, которых НЕТ в моём «уже есть».
- **Новые агенты**: папки в `agents/` клона, которых у меня не установлено.
- **Обновлённые агенты**: установлены у меня, но в репозитории (`marketplace.json` /
  `plugin.json`) версия выше моей — кандидаты на `update`.
Игнорируй всё, что у меня и так есть той же версии. Не предлагай переустановку.

## Шаг 4. Отфильтруй под мою пользу
Из дельты оставь только то, что реально полезно под мою роль и задачи (см. «О СЕБЕ»).
Не вываливай всю дельту подряд. Для каждого кандидата — одна строка: что делает и
почему пригодится именно мне. Если новизны под меня нет — честно скажи «нового
полезного нет», и на этом всё.

## Шаг 5. Спроси и установи
Покажи список кандидатов (новые скиллы + новые/обновлённые агенты) и спроси:
**«Ставим это? (всё / выбери номера / ничего)».** Жди ответа. Ставь только выбранное.

Установка (хосто-независимо):
- **Новые скиллы** — ссылками в общую папку `~/.agents/skills/` (её читают и Claude
  Code, и Codex), чтобы `git pull` в будущем подтягивал обновления:
    ln -s ~/team-skills/<путь-к-скиллу> ~/.agents/skills/<имя>
- **Новые агенты** (Claude Code):
    claude plugin marketplace add MichaelTarasov02/Skills   # если ещё не добавлен
    claude plugin marketplace update skills
    claude plugin install <agent>@skills
- **Обновлённые агенты** (Claude Code):
    claude plugin marketplace update skills
    claude plugin update <agent>@skills
- **Агенты в Codex** — линкуй их скиллы в `~/.agents/skills/` поштучно (единый линк
  на папку агента отдаёт только корневой скилл).

## Шаг 6. Проверь и объясни
- перечисли, что реально доустановил/обновил, настоящими путями;
- **скажи прямо: перезапусти агента (Claude Code — рестарт или `/reload-plugins`;
  Codex — новая сессия), иначе новое не подхватится**;
- покажи, как вызвать новое: Claude Code — `/<имя>`, Codex — `$<имя>`;
- если у скилла есть флаги — перечисли;
- дай 3 команды, которые я могу запустить прямо сейчас, чтобы попробовать новое.

## Жёсткие правила
- Только дельта: ничего, что у меня уже есть той же версии.
- Не выдумывай скиллы и версии — сверяй с клоном.
- Не удаляй и не переустанавливай работающее.
- Ничего не ставь без моего явного ответа на Шаге 5.
- Вызов зависит от хоста: Claude Code — `/name`, Codex — `$name`.

- Пользуюсь: Claude Code / Codex / оба: <<< ... >>>
- Где мой клон репозитория (если знаю): <<< напр. ~/team-skills >>>
```
