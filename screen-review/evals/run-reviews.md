# Прогоны `screen-review`

## Прогон 1 — web-экран ⚠️ живого открытия не было

**Честно о методе.** Playwright-прогон требует поднять Django-бэкенд, БД, авторизацию и
Vue dev-server. Это выходит за рамки разрешённого: запуск чужого стека с реальной базой
без явного согласия я не делаю. Ревью ниже сделано **по коду и по вычисленным цветам**,
и это сказано в самом ревью, как требует `references/vue.md`.

Экран: `whereami-server/whereami/src/views/active-associates.vue`, 178 строк.

### Находки — ранжированные

**Блокирующее**

**B1. Пять из семи самых частых цветов палитры не проходят контраст**
Что не так: `#10b981` (130 использований) даёт **2.54:1** на белом, `#f59e0b` (57) —
**2.15:1**. Оба ниже даже порога 3:1 для компонентов, не говоря о 4.5:1 для текста.
Почему это проблема: статусы, окрашенные в эти цвета, нечитаемы для части пользователей,
а поскольку цвет несёт смысл, смысл теряется целиком.
Правка: для текста и мелких иконок брать тёмный оттенок того же тона. `#2563eb` даёт
**5.17:1** и уже используется в проекте — новых цветов заводить не нужно. Для `#10b981`
и `#f59e0b` подобрать аналогичный тёмный шаг и добавить второй канал — иконку или слово.

| Цвет | Использований | На белом | Текст 4.5 | UI 3.0 |
|---|---|---|---|---|
| `#10b981` | 130 | 2.54 | fail | fail |
| `#f59e0b` | 57 | 2.15 | fail | fail |
| `#999999` | 32 | 2.85 | fail | fail |
| `#ef4444` | 101 | 3.76 | fail | pass |
| `#3b82f6` | 71 | 3.68 | fail | pass |
| `#2563eb` | 54 | 5.17 | **pass** | pass |
| `#6b7280` | 52 | 4.83 | **pass** | pass |

**B2. Ошибка загрузки оставляет пустой экран**
Что не так: `.catch` показывает `notification.error` и ничего не меняет на экране.
Тост исчезает, остаётся пустая таблица с дефолтным `No Data`.
Почему это проблема: нарушена эвристика 1 — через несколько секунд пользователь не
отличает «данных нет» от «загрузка упала», и повторить попытку нечем.
Правка: состояние ошибки на экране — `a-result status="error"` с сохранённым фильтром
и кнопкой повтора вместо тоста.

**B3. Экран не проверяет права**
Что не так: `grep -ci permission` по файлу → `0`, при том что в проекте есть
`permission-provider.vue` и `no-permissions.vue`.
Почему это проблема: пользователь без доступа к отчётам увидит пустую таблицу вместо
объяснения — нарушение эвристики 9.
Правка: гард на маршруте и рендер `no-permissions` вместо таблицы.

**Важное**

**B4. Три пустых состояния схлопнуты в одно**
Что не так: `grep -cE "a-empty|emptyText"` → `0`; `a-table` рендерит дефолтный `No Data`.
Почему это проблема: пользователь, выбравший период без данных, и пользователь без
ассоциатов получают один ответ, из которого не следует ни одного действия.
Правка: `a-empty` с тремя разными описаниями по причине; тексты — в `interface-copy`.

**B5. Термин в пользовательской строке расходится с продуктом**
Что не так: в файле `Associate` встречается 9 раз, включая `associate_number`, а
единственная строка, которую читает пользователь, говорит `Active Users Report`.
Почему это проблема: нарушение эвристики 2 и запрещённый синоним из `lexicon.md`.
Правка: `Active Users Report` → `Active Associates Report`.

**B6. Текст ошибки нарушает четыре правила стиля**
Что не так: `message: 'Error'` + «An error occurred…» + «Please» + «try to open this page
later» — обещание без срока и без действия.
Правка: передать в `interface-copy` вместе с B2.

**B7. Таблица не адаптируется по ширине**
Что не так: `:scroll="{ x: 600 }"` даёт только горизонтальный скролл.
Почему это проблема: на телефоне отчёт превращается в двумерную прокрутку.
Правка: на узких ширинах — карточный рендер вместо таблицы, либо явное решение, что
экран только для десктопа, зафиксированное в blueprint.

**B8. Дефолты кита не отревьюены**
Что не так: `No Data`, и кнопки модалок `OK` / `Cancel`, если экран их использует.
Правка: перечислить и переопределить; тексты — в `interface-copy`.

**Желательное**

**B9. Тёмной темы на web нет, а в мобильном приложении есть**
Что не так: Flutter несёт `ThemeType { light, dark, system }`, у Vue темы нет.
Почему это проблема: пользователь, переходящий между платформами, встречает два разных
продукта.
Правка: решение продуктовое — либо тема на web, либо явная фиксация, что web светлый.

### Неприменимо

R11 (расширение строк) и R12 (RTL) — в Vue-приложении нет i18n-слоя, строки не
переводятся и не зеркалятся. **Неприменимо, а не пройдено.** На мобильной половине те же
экраны несут семь локалей.

## Прогон 2 — Flutter, другой путь

Метод: чтение дерева виджетов и темы, без симулятора. Симулятор не запускался — сказано
прямо.

**Блокирующее**

**F1. Направляющие отступы не зеркалятся, а приложение поставляется на иврите**

```bash
$ grep -rE 'EdgeInsets\.only\((left|right)' lib | wc -l
228
$ grep -r 'EdgeInsetsDirectional' lib | wc -l
0
```

Что не так: 228 мест используют `EdgeInsets.only(left:/right:)`, `EdgeInsetsDirectional`
не используется ни разу. В RTL эти отступы остаются слева, когда всё остальное
отзеркалилось.
Почему это проблема: `intl_he.arb` существует, значит иврит поставляется пользователям,
и на нём вёрстка разъезжается по всему приложению, а не на одном экране.
Правка: `EdgeInsets.only(left: x)` → `EdgeInsetsDirectional.only(start: x)`. Замена
механическая и грепается; начинать с экранов, которые видит наибольшая часть
ивритоязычных пользователей.

**Важное**

**F2. 50 обращений к `Colors.white` / `Colors.black` при живой тёмной теме**
Что не так: тема с `ThemeType { light, dark, system }` есть и персистится, но 50 мест
берут цвет мимо неё. Плюс 8 литералов `Color(0xFF…)` вне `theme/` и `app_colors.dart`.
Почему это проблема: эти виджеты выглядят правильно ровно в одной из двух тем.
Правка: заменить на токены темы; список грепается, правка проверяема.

**F3. Тач-таргеты у не-кнопок**
Что проверять: `GestureDetector` вокруг `Icon` даёт цель 24×24 при минимуме 48×48.
Правка: `IconButton`, либо явный `SizedBox` до 48.
