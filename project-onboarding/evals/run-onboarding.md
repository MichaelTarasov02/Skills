# Прогоны `project-onboarding`

## Прогон 3 — режим C на реальном репозитории (главный)

Вход: только путь. Ничего не передано, ничего не сказано.

**Метрика качества: сколько полей обязательного минимума заполнено сканированием
до первого вопроса.**

| # | Поле | Заполнено | Источник |
|---|---|---|---|
| 1 | Что делает продукт, кто пользуется | ✅ | частотный анализ `intl_en.arb`: shift 352, company 324, associate 258, meal 254, break 242, payment 121, compliance 84, payroll 62, disciplinary 53 → учёт рабочего времени, перерывов и соответствия требованиям; роли Associate и Manager (`bb/models.py`, Manager 61 против supervisor 3) |
| 2 | Платформы и корни | ✅ | `pubspec.yaml` → Flutter в `whereami-flutter-2`; `package.json` → Vue 3 в `whereami-server/whereami`; Django в `whereami-server`. `web/dashboard/` распознан как **скомпилированный Flutter Web**, а не исходник — `flutter.js`, `canvaskit` |
| 3 | Язык интерфейса | ✅ | `intl_en.arb` — исходная локаль, 7 локалей всего, `he` RTL |
| 4 | Где живут строки | ✅ | Flutter: `lib/l10n/*.arb`, 3994 ключа, ICU-плюрализация. Vue: `vue-i18n` **отсутствует** → литералы в `<template>` |
| 5 | Дизайн-система | ✅ | Flutter: своя — `lib/theme/`, `app_colors.dart`, extensions, `ThemeType {light, dark, system}`. Vue: внешний кит `ant-design-vue`, Storybook нет |
| 6 | Подход к состояниям | ✅ | Flutter: `flutter_bloc` + `provider` + `get_it`, кубиты в фичах. Vue: булевы флаги в `data()` |
| 7 | Аналитика | ✅ | Flutter: `firebase_analytics ^11.4.2`. Vue: только `@sentry/vue` — мониторинг ошибок, не аналитика. `.telemetry/` **нет ни в одном репозитории** |
| 8 | Красные линии | ⚠️ частично | из домена выводится: meal break — юридический термин; `disciplinary` 53 вхождения; строка `"The Law requires you to take at least a {lunchDuration} meal break"` показывает, что продукт уже цитирует закон, а не утверждает соответствие. Подтверждение и полнота — за человеком |

**Семь из восьми полей заполнены полностью до первого вопроса. Восьмое — частично.**

Вопросов задано: **один**, а не четыре.

```
Красные линии выведены из домена, но требуют подтверждения:
(а) Есть ли ограничения сверх трудового законодательства США — отраслевые,
    контрактные, требования конкретных клиентов?
(б) Что запрещено обещать в ответах пользователям помимо сроков?
```

Всё остальное из желательного ушло в допущения — тип продукта B2B помечен
`source: assumption`, отрасль осталась `unknown`.

### Асимметрии — записаны отдельно, а не усреднены

| Асимметрия | Кого касается |
|---|---|
| mobile локализован на 7 языков, web одноязычен | `interface-copy`, `screen-review` |
| mobile имеет продуктовую аналитику, web не имеет | `element-markup`, `feature-handoff` |
| mobile имеет тёмную тему, web не имеет | `screen-review` |
| разные дизайн-системы: своя против внешнего кита | `screen-blueprint` |

Усреднить их в один ответ уровня проекта значило бы соврать обеим половинам команды.

## Прогон 2 — режим B

Вход, абзац с намеренными пробелами:

> «Это приложение для учёта рабочего времени. Работники отмечают приход и уход,
> менеджеры смотрят отчёты. Мобильное на Flutter, веб на Vue.»

Не сказано: язык интерфейса, красные линии.

**Вопросов задано: 2** — ровно по пробелам.

```
(а) На каком языке интерфейс говорит с пользователем?
    Вижу в lib/l10n/ семь локалей с en как исходной — подтвердить?
(б) Что продукт не имеет права обещать пользователю?
```

Не переспрошены: что делает продукт, кто пользуется, платформы — всё это было в тексте.
Про дизайн-систему, строки, состояния и аналитику не спрошено — взято из кода.

Первый вопрос сформулирован с готовым вариантом, а не как открытый.

## Прогон 4 — приоритет источников

**Вход:** «У нас на вебе i18next, строки в locales/».

**Выход:**

```
Расхождение. Сказано: i18next. В коде: whereami-server/whereami/package.json
не содержит ни i18next, ни vue-i18n; строки лежат литералами в <template>.

Записываю версию кода. В config.yaml:
  strings.library: { value: null, source: code, note: "vue-i18n absent" }

Если i18next планируется, это не текущее состояние, а решение — оно попадёт
в onboarding.md как «предположено», не как «известно».
```

Молчаливого выбора не произошло: обе версии показаны, приоритет назван.
